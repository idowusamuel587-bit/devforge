# Contributing to DEVFORGE

Thank you for your interest in contributing to DEVFORGE!

We welcome bug reports, documentation improvements, accessibility fixes,
new features, and suggestions that make the project more useful.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install Node.js 20 or later.
4. Create a branch for your changes.
5. Make your changes and run the tests.
